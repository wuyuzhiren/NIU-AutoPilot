## 一、App 内自动更新流程（工作原理）

```
启动 App → 检查更新（checkUpdate）→ 读取远端 version.json
```

## 四、签名与打包（铁律，全部实测验证）

### 1. 签名密钥（固定，不可换）
| 项 | 值 |
|---|---|
| 密钥文件 | `E:\小牛自用\NIUAutoPilot\app\debug.keystore` |
| storepass / keypass | `android` |
| 别名 alias | `androiddebugkey` |
| SHA-256 | `1ecc4b8856a34a3879599e49ac4e72f86a6e0a8cbe3eb64025efef271bf3e9a3` |

> 每次发版必须用此密钥重签，否则无法覆盖安装（INSTALL_FAILED_UPDATE_INCOMPATIBLE）。

### 2. 工具路径
| 工具 | 路径 |
|---|---|
| Java | `E:\Dev\android-build\jdk-17.0.13+11\bin\java.exe` |
| build-tools | `E:\Dev\Android\sdk\build-tools\34.0.0`（zipalign / apksigner / aapt / dexdump） |
| apktool | `E:\Dev\android-build\apktool.jar` |
| adb | `E:\Dev\Android\sdk\platform-tools\adb.exe` |
| 真机 | `db34c1bf`（小米 Redmi） |

### 3. 打包命令（顺序绝对不能错）
```
1) 反编译（改代码/资源用）
   java -jar apktool.jar d 原.apk -o 解包目录

2) 重打包
   java -jar apktool.jar b 解包目录 -o 输出-unsigned.apk

3) 对齐（必须先对齐再签名！）
   zipalign -f 4 输出-unsigned.apk 输出-aligned.apk

4) 签名
   $env:JAVA_HOME = "E:\Dev\android-build\jdk-17.0.13+11"   ← 必须先设，否则 apksigner 报错
   apksigner sign --ks app\debug.keystore --ks-pass pass:android --key-pass pass:android --ks-key-alias androiddebugkey --out 最终.apk 输出-aligned.apk

5) 验证签名
   apksigner verify --print-certs 最终.apk
```

### 4. 打包顺序的两个坑（实测踩过）
- ⚠️ **必须先 zipalign 再 apksigner**。先签名再对齐 → 安装报 `INSTALL_PARSE_FAILED_NO_CERTIFICATES`。
- ⚠️ **apksigner 前必须先设 JAVA_HOME**，否则找不到 java 直接失败。

### 5. 安装到真机
```
adb install -r 最终.apk          # 升级安装
adb install -r -d 最终.apk       # 降级安装（调试旧版时用）
```

## 五、发版完整流程（每次发版必须全套）

```
1. 改代码/资源 → 迭代版本号（apktool.yml：versionCode / versionName）
2. 按第四节打包 + 固定密钥签名 → 真机验证不闪退
3. 把 APK 放进仓库 releases/ 目录（命名 app-vX.X.apk）
4. git push 到 GitHub main 分支
5. 创建 GitHub Release（tag=vX.X），上传 APK 附件
   POST https://api.github.com/repos/wuyuzhiren/NIU-AutoPilot/releases
   POST https://uploads.github.com/repos/wuyuzhiren/NIU-AutoPilot/releases/<id>/assets?name=app-vX.X.apk
6. 更新 version.json（versionCode / versionName / downloadUrl / changelog）
   用 GitHub API PUT contents/version.json（先 GET 拿 sha 再 PUT）
7. 回读确认：version.json 内容、Release asset 大小与本地一致
8. 告知用户新版本，App 内自动更新即会提示
```

### 发版检查清单（铁律）
- [ ] 固定密钥重签（debug.keystore）
- [ ] APK 上传 GitHub releases/（仓库内文件 + Release 附件）
- [ ] version.json 同步（版本号 / 下载地址 / 更新说明）
- [ ] 版本号迭代（versionCode 递增，保证覆盖更新）
- [ ] 真机验证启动不闪退、关键功能正常
